# xray-onexray-reality

## 一条命令安装

SSH 登录 VPS 后执行：

```bash
curl -fsSL https://raw.githubusercontent.com/www222fff/xray-onexray-reality/main/install.sh | bash
```

装完后终端会显示二维码，用手机 OneXray 扫码导入即可。
